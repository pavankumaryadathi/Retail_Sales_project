# 🛒 Retail Sales Analytics & Customer Performance Project

An end-to-end retail data analytics project analyzing **50,000+ retail transactions** using **MySQL** and **Power BI** to uncover revenue drivers, product category performance, seasonal trends, and customer purchasing behavior.

---

## 📌 Project Overview

This project transforms raw retail transaction logs into an interactive business intelligence solution. The workflow spans relational database querying and KPI validation in **MySQL**, followed by star-schema data modeling, DAX calculations, and executive dashboard design in **Power BI**.

### Core Objectives
- **Sales & Revenue Tracking:** Monitor total revenue, order volume, profit margins, and average order value (AOV) across regions and store locations.
- **Product & Category Insights:** Identify top-performing product categories, high-margin SKUs, and underperforming inventory.
- **Customer & Seasonal Trends:** Analyze repeat purchase behavior, customer segments, and peak sales periods to support inventory and marketing decisions.
